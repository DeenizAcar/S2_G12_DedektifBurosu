## Kurulum ve Çalıştırma

1. Projeyi PyCharm'da açın.
2. `requirements.txt` için PyCharm'ın önerdiği **Install requirements** uyarısını kabul edin.
3. `kod/main.py` dosyasını çalıştırın.
